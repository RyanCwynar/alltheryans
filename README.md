# All The Ryans

A static encyclopedia of notable people named Ryan.

## Stack

- Plain **Lit 3** web components as ES modules (import map + CDN)
- No bundler, no Vite, no Next.js, no prerender, no database
- Content: `ryans/*.md` with YAML frontmatter (infobox, clusters, relationships, sources)
- Publish gate: `status: published` (drafts stay in git, out of the public index)
- `ryans/index.json` regenerated by GitHub Action (catalog + tags + Ryan-web graph)

## Local preview

```bash
python3 scripts/serve.py --port 4173
```

Open `http://127.0.0.1:4173/`. The helper mirrors `vercel.json` rewrites for `/ryan/:slug` and `/tag/:slug`.

## Frontmatter (mapped from the Postgres proposal)

Key fields: `slug`, `name`, `number`, `status`, `short` (≤25 for cards), `title`, `photo` (+ credit/license), `birth`, `education`, `occupations`, `clusters`, `organizations`, `social`, `known_for`, `relationships`, `sources`, `featured_on`.

## Adding / publishing a Ryan

1. Add `ryans/<slug>.md` (or `NN-<slug>.md`) with frontmatter. Default `status: draft`.
2. Set `status: published` when ready for the public site.
3. Push. The workflow updates `ryans/index.json` (nodes/edges from relationships among published Ryans).

## Pages

- `/` — Ryan of the day (`America/Sao_Paulo`, or `featured_on`)
- `/archive/` — grid with cluster filter + sort
- `/tag/<cluster>` — cluster page (e.g. `/tag/actor`)
- `/ryan/<slug>` — encyclopedia bio (infobox + footnotes)
- `/web/` — Ryan web graph (d3-force, client-side)
- `/about/`

## Deploy

Static files on Vercel (or any static host). Do not require a build step.
