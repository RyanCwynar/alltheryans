# All The Ryans

A static directory of notable people named Ryan.

## Stack

- Plain **Lit 3** web components loaded as ES modules (import map + CDN)
- No bundler, no Vite, no Next.js, no prerender
- Content: `ryans/<slug>.md` with frontmatter, fetched and rendered in the browser
- `ryans/index.json` is regenerated by a GitHub Action on push (CI, not a site build)

## Local preview

Serve the repo root as static files (any static server):

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.

## Adding a Ryan

1. Add `ryans/<slug>.md` with frontmatter (`slug`, `name`, `short` ≤ 25 chars, `title`, `photo`, `photo_credit`, `photo_license`, `sources`, optional `featured_on`).
2. Push. The workflow updates `ryans/index.json`.

## Deploy

Static files on Vercel (or any static host). `vercel.json` rewrites `/ryan/:slug` to `index.html` for client routing.
